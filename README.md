# Prioritized Replay Meets Predictive Maps: A Hippocampus-Inspired Agent for Rapid Adaptation in Changing Environments
Authors: Elizabeth Kao, Skylar Belsher, Siddhant Bhardwaj

## Abstract
Animals can adapt quickly when a reward moves or a path gets blocked, yet most deep RL agents require many additional trials to adapt. In this project we test if a brain-inspired agent can adapt faster. Our agent combines successor representations (SR), which work like a map of future states, with Dyna-style replay that picks which memories to replay using a "need x gain" rule. Rather than using a pre-existing dataset, we generate data by simulation in large multi-room mazes of around 25x25 to 30x30 cells, where the agent slips 10% of the time. After training, we change the reward, rewire the maze, or block/open a path. We compare Q-learning, Dyna-Q, a model-based planner, SR-TD, SR-Dyna, and SR with prioritized replay across 50+ random seeds. We evaluate success using two categories of metrics. The first category assesses behavior and computational efficiency by tracking the number of episodes needed to reach 90% of the way from random to optimal post-change performance, the area under the post-change learning curve, the online regret relative to the optimal policy, and the total number of replay updates. The second category involves neurobiological checks to confirm whether the model mimics biological brains, specifically by measuring the fraction of forward versus reverse replay events and determining if the learned successor representation features resemble hippocampal place fields.
